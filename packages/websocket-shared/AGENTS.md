# @ainess/websocket-shared 开发指引

公开协议与用法见[使用手册](README.md)。

- 本包维护命名 WebSocket 端点的帧类型、编解码、模式枚举和流读写辅助逻辑，供服务端和客户端共用。
- 包使用浏览器和 Node.js 共通的 JavaScript API 与类型。运行时依赖为空。连接、重连、路由注册和鉴权由消费方管理。
- `WebSocketMethodMode` 的四个值与仓库 RPC 模式对齐。通过 `id` 关联同一连接的调用、分片与终态。收到外部帧时用解码器验证消息信封，业务 Schema 由所属端点在入参边界使用。
- 流队列对缓存分片和等待读者使用相同的链式 FIFO，单次入队和取出为常数操作。消费方通过结束、取消或失败释放读者。发送方按顺序发送，协议不交换额度。`waitWithAbort()` 让等待中的流读写和异步校验响应同一个取消信号。
- 运行根目录 `pnpm test` 验证协议、客户端和真实服务端连接，公共包的帧与流取消测试放在 `test/`。
